# Демо-урок 01 — сценарий

**Предмет:** русский язык (как второй), **формат:** онлайн, Zoom, один преподаватель — один ученик, запись ≈ 35 минут.
**Преподаватель:** Айгерим Сериковна. **Ученик:** Данияр, 6 класс, казахская школа, родной язык — казахский.
**Тема:** падежные окончания имён существительных: предложный и дательный падеж. **Второй сюжет:** правописание -тся / -ться.

Этот файл сгенерирован из `demo/make_transcript.py` вместе с `transcript.json` — таймкоды совпадают.
Кадры экрана (`frames/NNNN.jpg`, `frames.json`) создаёт `demo/make_frames.py`; номера кадров указаны в описании разделов.
